# 02｜微信小程序 UI/UX 与前端设计

## 1. 实现选择
原生小程序 TypeScript + WXML/WXSS，微信开发者工具构建。MVP 避免把 Next.js Web 视图包在 web-view 中；遵循小程序网络、授权和文件能力。页面栈轻量，首屏只做必要初始化。颜色采用温暖的奶油白 + 深色正文 + 低饱和珊瑚色强调，不使用过度童化的复杂动画，保证祖辈易读。

## 2. 页面路径（建议）
```text
pages/onboarding/index      欢迎/AI 内容提示/隐私入口
pages/create/index          选照+提示+校验
pages/customize/index       主题、昵称、音色、时长、文案
pages/job/index             任务进度、失败、重试
pages/result/index          视频预览/保存/删除
pages/gallery/index         我的作品、数据管理
pages/settings/index        隐私、客服反馈、用户删除
```
避免把照片、昵称或 token 放入页面 URL、分享路径或埋点标签。

## 3. 关键交互
- **选择照片**：`wx.chooseMedia({count:1,mediaType:['image']})`（以当前小程序基础库能力为准，真机验收）；本地只展示缩略预览，原图以 `wx.uploadFile` 上传 API。文件类型、大小和尺寸服务端复核，不能只信扩展名。
- **登录**：`wx.login` 后调用 `POST /v1/auth/wechat`；未登录可浏览介绍，提交之前必须认证并取得法律要求的授权。
- **隐私同意**：采用微信隐私接口和业务侧版本化知情/监护确认的两层机制；微信平台的隐私同意不能替代法律要求的监护人同意。记录文档版本、时间、来源和最小证据。
- **创建任务**：按钮提交后立即禁二次点；`Idempotency-Key` 由客户端生成并持久化到任务创建成功，弱网重复使用同键。显示“已受理”“语音制作中”“视频制作中”“质检中”等阶段。
- **轮询**：前台初始 3s，逐步退避至 10s+随机抖动；页面隐藏停止，页面显示恢复；超过阈值提示“可稍后在我的作品查看”，不是“生成失败”。服务器没有阶段百分比时不展示 80%/99%。
- **下载保存**：服务端鉴权签短期下载 URL，使用 `wx.downloadFile` 下载再调用 `wx.saveVideoToPhotosAlbum`；本地权限拒绝要有引导但不可强迫；下载 URL 不得发到分析系统。
- **分享**：首版优先保存相册后让用户使用微信分享；不开发默认公开网页。未来带令牌私密短链需支持失效、撤销、访问次数限制及预览隐私保护。

## 4. 任务页状态映射
| 服务端 | 文案 | UI |
|---|---|---|
| QUEUED | 排队中，您可以先离开页面 | 不显示假百分比 |
| PREPROCESSING | 正在检查照片 | 阶段性提示 |
| SYNTHESIZING | 正在制作声音 | 阶段性提示 |
| GENERATING | 正在制作宝宝视频 | 允许离开 |
| QUALITY_CHECK | 正在检查视频效果 | 避免承诺必定成功 |
| RENDERING | 正在合成最终视频 | 允许离开 |
| COMPLETED | 视频已完成 | 观看/下载/删除 |
| REJECTED / FAILED | 未能生成，查看原因 | 帮助/重新选图/有限重试 |
| CANCELLED / EXPIRED | 已取消 / 已过期 | 新建任务或说明 |

## 5. 网络、安全与可达性
必须配置合法 HTTPS request/upload/download 域名，不能把 `api.weixin.qq.com` 配为小程序客户端请求域名；微信的 appsecret 只在后端。上线环境域名、备案及小程序类目/审核规则应按实际主体与所在地复核。
校验登录令牌过期（401）并安全重登；401 不应无限重复提交任务。弱网断点恢复以服务器 job_id 为准。所有上传展示可重试并保留本地表单（不持久化儿童原照到无保护缓存）。输入限制和防抖仅是交互优化，服务端必须独立鉴权、限频和校验。

## 6. 无障碍和祖辈友好
字号可放大、触控目标≥44px 作为设计目标，减少复杂手势；每一步明确反馈；语音样片可先试听（不上传用户儿童素材）；失败和权限弹窗使用可理解中文。强调“这是 AI 创作，不是真实语音”。
