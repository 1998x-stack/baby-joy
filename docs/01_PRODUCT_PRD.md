# 01｜产品需求文档 PRD

## 1. 产品目标
让刚添新成员的家庭，把原本不能说话的宝宝照片变成“宝宝送给家人一句祝福”的 **明确标为 AI 创作的趣味纪念视频**。消费者是成人监护人；情感接收者是爸爸妈妈和祖辈。不能宣传为宝宝真实说话或真实录音。

## 2. 角色
- 父母/法定监护人：登录、完成授权、上传和管理作品。
- 祖辈：主要观看和收藏。MVP 允许收到监护人主动发出的本地视频，不单独允许祖辈以第三人儿童照片创建。
- 运维/审核人员：仅在可审计且授权最小化的流程里处理举报/失败；默认不能浏览原图。
- 系统：自动文本检查、图像检测、语音生成、视频生成、质检、清理。

## 3. 核心用户故事及验收

| ID | 故事 | 验收 |
|---|---|---|
| U01 | 我想快速用微信开始 | wx.login 换会话、失败提示、服务端仅以签发令牌识别用户 |
| U02 | 我想知道照片将如何处理 | 上传前告知用途/时限/AI 创作/授权，保留版本化同意记录 |
| U03 | 我上传宝宝照片 | JPG/PNG/WEBP，单图≤8MiB；验证真实 MIME、尺寸和单脸；错误明确可重选 |
| U04 | 我选择一句适合家人的话 | 选择内置模板，支持宝宝称呼和收件人昵称；注入/违禁内容不会流入 GPU |
| U05 | 我选择声音和视频时长 | 3 个授权 TTS 音色候选、6/8/12 秒；真实音频过长时要求调整而非裁断 |
| U06 | 我提交后能知道系统没卡住 | 异步返回 job_id，后台展示阶段、可退出再进入；无凭空进度百分比 |
| U07 | 结果可保存给家人 | 成品预览、保存到相册（取得设备授权）、私有下载有时效；视频带 AI 标识 |
| U08 | 我不满意或失败 | 失败显示可理解原因，有限重试不重复扣配额；没有伪成功 |
| U09 | 我能控制照片和作品 | 删除请求可以追踪，最终删除原图/中间件/成片，最小化留下必要审计痕迹 |
| U10 | 我能请求支持/投诉 | 反馈入口、问题编号、处理状态，审计后台不得直接暴露儿童素材 |

## 4. 主流程
首次打开 → 功能/隐私说明 → 微信登录 → 单独监护人授权及用途告知 → 选图 → 上传并质检 → 选模板/称呼/音色/时长 → 生成请求与配额预留 → 任务详情（可离开）→ 完成推送/轮询 → 观看/保存/删除。

重进小程序时恢复最近待处理任务；不能依赖小程序常驻或 WebSocket 长连接。

## 5. MVP 输入与输出规范
- 图片：1 张；8MiB 上限；JPG/PNG/WEBP；最低建议 512px 短边；正面清晰、单脸，无严重遮挡。建议值可根据 benchmark 修改。
- 文本：三种场景模板；变量用户输入经过 Unicode 正规化、最大长度和服务端审核。私测可允许 60 汉字以内有限自由编辑。
- 语音：仅授权的合成童趣声音；拒绝“克隆这个婴儿真实声音”的产品承诺；不允许用户上传不明来源声音。
- 视频：6/8/12 秒目标上限；9:16；720×1280 交付分辨率为目标，实际需要以 GPU benchmark 验证。支持 MP4/H.264、AAC。
- 明示“AI 趣味创作”；成品考虑可见角标与文件内隐式标识；不得保证所有转发链路完整保留隐式信息。

## 6. 页面与错误体验
页面：欢迎/知情、创作、图片检查、祝福配置、任务进展、视频详情、我的作品/隐私设置。
错误码向用户映射：图片模糊/多脸/违规/时长不符/暂时繁忙/生成失败/凭证失效/权限拒绝；绝不显示 Python traceback 或模型路径。

## 7. 指标体系
北极星：**有效监护授权用户中，满意并主动保存的一次成功作品占比**。漏斗：开始授权→完成上传→通过图片校验→提交→成功交付→保存→主动分享（可在不追踪具体对象的情况下统计）。质量：家长相似度满意度、畸变拒收率、音画同步、P95排队时间、生成成功率、资源成本/成功片、投诉率、主动删除 SLA。

内部预设阈值（需后续论证）：有效请求成功率≥95%；“仍像宝宝”满意率≥85%；用户满意≥4/5。任何报告须注明人数、输入样本与是否付费样本；避免唯成功样本统计。

## 8. 版本范围
- MVP：监护人单账户、照片+语音模板、异步制作、作品列表、私密保存、主动删除、人工反馈。
- P1：更好年龄动作模板、模版库、明确授权后的家庭成员协作、私密分享短链（审计与撤销）。
- P2：多人合影、故事视频、长期纪念册、收费与权益；均需重新评估许可与儿童信息风险。

## 9. 退出条件
G1 婴儿真实样本验证不通过、许可不明、隐私审查不通过、投诉处理无能力、GPU 成本远超付费意愿时，停止公开上线并迭代研究。严禁通过精选 Demo 掩盖实际失败率。
