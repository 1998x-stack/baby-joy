# 00｜MVP 决策摘要

> 状态：设计提案；Owner 待定；2026-11-19

## 1. 要解决的问题
一张宝宝照片生成一段私人家庭祝福。真正的“产品完成”是让监护人看到一段**仍像自己孩子**、音画协调、自然可爱的可保存作品，而不是仅有技术演示。产品面向成人监护人，不面向儿童独立使用。

## 2. 不变的第一版约束

1. **微信原生小程序**作为唯一客户端；后端统一处理生成，所有计算和存储在服务端。小程序不持有微信 AppSecret、模型权重、对象存储永久密钥。
2. **登录**：wx.login -> 服务端 code2Session -> 本站短期访问令牌；openid 仅服务端留存。禁止以客户端传入 openid 作为身份依据。
3. **素材**：MVP 单张正面/半侧面照片，单人儿童，不接受用户上传音频/语音克隆；中文内置文案，经过审核的童趣 TTS。
4. **媒体**：计划提供 6/8/12 秒三档；最终时长以实际语音长度、模型支持窗口和合成验收为准，不能静默裁断文本；9:16 H.264 MP4 + AAC。
5. **流程**：API 创建异步任务，Redis/Celery 或等价队列执行，PostgreSQL 做真实任务状态与幂等；小程序轮询展示**有证据的阶段**，不展示虚构百分比。
6. **保密**：对象存储私有；短期授权下载；无公开素材 URL；默认不用于训练；上传前完成必要告知和监护授权记录。
7. **商业策略**：内部 Alpha 免费且配额限制；支付、多人视频、用户任意音频、开放社交分享均延后，避免过早扩范围。

## 3. 系统边界

```text
微信小程序
   | wx.login / wx.uploadFile / wx.request  (HTTPS)
   v
API 网关 -> FastAPI/BFF -> Postgres(状态与授权)
                         |-> 私有 S3/MinIO(原图/音频/视频)
                         |-> Transactional Outbox -> Redis -> CPU Worker
                                                         -> GPU Worker (TTS + 视频模型)
                                                         -> QC / FFmpeg
                                               <状态/结果> 
   ^ GET /jobs/{id} 轮询; GET /jobs/{id}/download 获取授权地址
   |
微信小程序
```

“统一后端生产”代表**只通过本系统 API 接单，任务由本系统服务器调度和交付**；GPU 可位于同机或可信私网节点，绝不将生成逻辑搬到客户端。若服务器没有可用 NVIDIA GPU，则只能跑 Mock 端到端，不能声称真实视频模型可用。

## 4. 阶段性决策（Go / No-Go）

| Gate | 最小证据 | 失败则 |
|---|---|---|
| G0 模型许可 | 项目/权重/依赖的商业使用、分发和地域许可清单 | 不进入商业部署 |
| G1 婴儿效果 | 30–50 张合法授权照片；盲评相似度、口型、畸变；同输入模型对照 | 缩小动作/调参/换模型，不扩大产品 |
| G2 API 安全 | 授权越权、重放、上传非法内容、幂等和并发测试通过 | 不开放用户 |
| G3 真机闭环 | 小程序真机登录上传、弱网重试、异步生成、相册保存、删除全成功 | 不发布小程序 |
| G4 合规 | 儿童个人信息、AI 标识、微信平台规则及应完成的备案/评估通过审查 | 不公开上线 |

目标（非实测）：有效照片任务成功率 ≥95%；家长认为“仍像宝宝”≥85%；主观满意度≥4/5；对身份变形设置拒绝交付门禁。必须同时报告样本规模和置信度/分布，不能只报平均值。

## 5. 起步技术组合

- Client：微信原生 TypeScript + WXML/WXSS；简洁、微信官方调试链友好。
- API：Python FastAPI + Pydantic；PostgreSQL；Redis + Celery（队列）。
- CPU Worker：Pillow/OpenCV、MediaPipe（受限场景可回退）、FFprobe/FFmpeg、内容审查接入点。
- GPU：适配器模式接 EchoMimicV3-Flash 首先做质量验证，对照 InfiniteTalk 与 Wan2.2-S2V；TTS 首选 CosyVoice 候选，最终据评测决定。
- Storage：S3 兼容私有桶；本地 Alpha 可 MinIO，正式环境定备份与对象生命周期。
- Deploy：Docker Compose（单管理节点 + 可选独立 GPU 节点）；后期确有并发再上 Kubernetes。

## 6. 先不做

商业支付、用户社区、公开可搜索链接、多人物合拍、真人宝宝语音克隆、从零训练视频模型、3D/VR、无限时长和海外多地区合规。每一个都引入额外隐私、质量或计算复杂度。
