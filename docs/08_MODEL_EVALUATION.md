# 08｜Baby Benchmark：模型、语音和视频质量实验

## 1. 首轮研究问题
P1：单张婴儿照片+中文短句，现有开源模型是否生成“仍像这个宝宝”的可信短片？
P2：哪个模型在质量足够好的情况下具有更低成本/更高成功率？
P3：是否需要做 Baby-Aware motion 控制层，而不是立即微调大模型？

## 2. 测试集构建
目标 30–50 张**明确监护授权**照片（不是未经许可网络爬图），跨年龄段（由家长自报）、姿态（正脸/轻侧脸）、光照、皮肤色调、衣物背景与画质。不可记录与评估无关的姓名、健康信息等。每张使用 3 种文案长度和 2 种音色，在各模型上保持可重复种子、分辨率和时长规范。照片可只用于短期评测，按照授权范围及期限销毁；不要将测试素材提交 Git 仓库。

## 3. 实验矩阵
| 维度 | 值 |
|---|---|
| 视频模型 | EchoMimicV3-Flash、InfiniteTalk、Wan2.2-S2V（许可证与 GPU 资源先审） |
| TTS | CosyVoice 候选 + 1 个具可用商业权利的对照 |
| 文案 | 6 秒短祝福、8 秒标准祝福、12 秒较长祝福 |
| 图片 | 正脸、轻侧脸、戴帽/遮挡、低光 |
| 生成 | 固定 checkpoint、config、seed、驱动 audio hash |
| 质量 | 盲评、失败率、定量口型/时间一致性、资源监测 |

每个生成尝试都有 run manifest：`case_id, consent_ref, image_sha256 (仅安全环境), audio_sha256, model_version, weights_checksum, seed, CUDA, GPU, params, status, latency, outputs, evaluator_version`。输出访问必须受控，评测汇总可公开但不公开原图/儿童脸部视频。

## 4. 质量评分（原始建议权重）
- **身份与相似度 30%**：家长盲评“是否还像自己宝宝”；成人 ArcFace 类指标不能单独当判定。
- **运动自然 20%**：眨眼、下巴、头部、嘴巴与婴儿年龄合适程度。
- **音画同步 20%**：中文音素/口型时序；可用 SyncNet 类指标辅助，但要针对婴儿分布检验。
- **时间连续性 15%**：嘴部、肤色、眼睛、衣服、背景跳帧。
- **情感趣味 10%**：自然亲切、声音无冒犯及幼态违和。
- **效率与成本 5%**：GPU 秒/成功片、峰值显存、总重试率。

重大失真（面部成人化、异常牙齿、身份替换、违规输出）为 **硬门禁**：即使均分高也不能交付。主观评分建议盲评，随机化顺序并让家长评价自己的宝宝和第三方标注者分别评价自然度，避免由单一评审决定。

## 5. 指标和统计
- `first_pass_success_rate`：第一次生成且通过 QC / 有效请求数。
- `delivered_success_rate`：在允许重试预算内完成并通过 QC / 有效请求数。
- `identity_acceptance_rate`：家长明确答“像自己的宝宝”的比例（只在实际获得评分的交付中报告，同时报告响应率）。
- `bad_artifact_rate`：各类异常数量/生成候选数。
- `latency_p50/p95`：分别统计排队、GPU、后期、端到端。
- `cost_per_accepted_video`：所有成功、失败尝试的资源成本总额/最终合格视频数。
样本较小时报告置信区间、样本数和照片分层；不宜凭几十张照片宣称全面泛化。

## 6. 实验记录文件约定
```text
benchmarks/
  README.md
  manifests/experiment-YYYYMMDD.jsonl  # 脱敏，不提交用户图片和授权凭证
  reports/experiment-YYYYMMDD.md       # 原始基线和决策
  tools/                               # 后期实现测量脚本
```
质量评测平台必须支持 `not_run`、`failed`、`passed` 三态；没有实际运行不得补写 PASS。

## 7. 决策门槛与下一步
内部 Alpha 进入条件（设计目标，非实测）：家长相似度接受≥85%、交付成功率≥95%、重大脸部扭曲有可靠拒收机制、真实 GPU 成本落在产品允许区间，且商业许可证审查通过。任一主要分层明显偏低则扩大样本/修正问题，不用整体均分掩盖。
优先先做低动作幅度、对齐预处理与 voice prosody；最后才考虑 LoRA 或专用婴儿数据训练，后者还需要明确的授权范围、数据治理和伦理审查。
