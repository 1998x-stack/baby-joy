# 09｜儿童肖像、隐私、安全与合规设计

> 产品涉及真实婴幼儿肖像、未成年人个人信息和深度合成视频。下列为技术控制与合规审查清单，**不能取代法律意见或监管备案判定**。上线前由实际运营主体及法律专业人员按部署地域确认。

## 1. 数据分级
- **高敏素材**：儿童原照片、面部视频、音频作品、家庭昵称/人物关系；加密私有存储，最低权限访问，不送普通日志/APM/未签约第三方。
- **身份数据**：openid、内部用户 ID、监护授权证明、IP 和设备元数据；最小化保留，使用分权或 KMS 管理。
- **运行数据**：stage、错误码、延迟、GPU 峰值、模型版本；默认匿名或去标识化，必须防反向关联。
- 不采集儿童真实姓名、出生证件、面部识别模板、地理位置、健康或学校信息；不进行无关儿童属性推断。

## 2. 授权与使用边界
- 仅允许父母/其他法定监护人启动生成；祖辈或朋友不能因持有照片自动获得创建权限。若未来允许祖辈代办，必须建立真实可核验的监护人授权流程。
- 小程序展现照片用途、音视频生成、AI 属性、保存时限、受托处理方、撤回和删除渠道；业务后端持久记录同意版本、scope、时间、必要证据。
- 若儿童未满 14 周岁，应按照中国个人信息保护法相关要求取得父母或其他监护人同意并制定专门处理规则；实际适用需按地域确认。
- 禁止上传真实儿童素材做任何未经单独明确合法授权的模型训练；私测素材也不例外。
- 对生成内容进行明显“AI 合成”提示，同时按适用规范设计文件隐式标识；不能提供轻易移除平台必要标识的功能。后期分享/重新编码时标识可能丢失，需要产品提示和技术验收。
- 内容审核：允许家庭祝福、节日生日等；阻止性化未成年人内容、欺骗/冒充真实儿童表达、侮辱恐吓等，提供人工举报入口。
- 产品不是面向儿童的陪聊/依恋交互机器人；如产品演变为持续拟人化对话应重新评估 2026 年拟人化互动相关规范的适用性。

## 3. 威胁模型
| 威胁 | 攻击路径 | 控制 |
|---|---|---|
| IDOR 越权看他人宝宝 | 猜测 job_id 或 asset_id | 所有 GET/DELETE 都强制 `user_id` 校验；随机 UUID；404 不泄露存在性 |
| 外部 URL SSRF | 提交 image_url 指向内网 | MVP 不接收任意 URL；上传本地文件，禁止 worker 外网抓取 |
| 恶意图像/解码炸弹 | 巨大像素、畸形格式 | 流式限额、magic sniff、像素上限、隔离解码、CPU/内存限制 |
| Token 泄露 | 小程序/日志/链接暴露 | 短期令牌、按端撤销、禁止日志打印；微信 AppSecret 只后端 |
| 对象泄露 | 桶公开、长效签名 URL | private bucket + KMS、每次下载鉴权、短期签名、禁止转存 URL 到埋点 |
| 数据删除不彻底 | CDN/副本/worker cache/备份 | 删除任务扫描、生命周期清理、恢复后删除重放、删除审计 |
| 错误扣费/重试风暴 | 客户端重复 POST / 队列重投 | Idempotency Key、配额原子预留、worker fencing、死信队列 |
| Prompt/命令注入 | 将文本插入 shell 或任意提示 | 服务端模板 allowlist，不用 shell 拼接，把模型参数固定在配置 |
| 内部人员越权 | 管理员浏览素材 | RBAC、双人审批、只读受限操作、访问审计、临时授权 |

## 4. 数据处理生命周期（拟议默认）
- 图片：上传后在隔离区扫描；源图最长建议 7 天（除非用户更早删除）；必须与告知一致。
- TTS 和未完成视频：建议 24h 内自动清理。
- 成品：建议 30 天到期；用户可提前删除；后续可提供用户主动选择保留更久。
- 删除请求：先使资源不可见、撤销未失效的签名（签名 URL 已签发可能暂不可撤销，优先短 TTL/代理流），中止排队并标记 GPU 丢弃结果，再异步逐层删除。给出删除跟踪状态和失败告警。
- 数据库审计、备份及灾难恢复副本的合法保留期限须单独审查；恢复时运行删除记录重放，不得复活用户要求删除的内容。
- 不以“删除 DB 行”替代物理对象/临时目录删除。

## 5. 上线审查矩阵
| 项目 | 必须核对 |
|---|---|
| 小程序 | 主体、合法服务器域名、域名备案、类目、隐私保护指引、微信审核和有关 API 可用性 |
| 个人信息 | PIPL、未成年人信息处理规则、告知/监护同意、第三方处理者 DPA、跨境传输（如有） |
| AIGC | 生成式 AI 服务、深度合成算法/服务相关规定及标识规范、是否需要备案或安全评估，由合规负责人判断 |
| 版权/开源 | 模型底座/权重/声库/BGM/代码许可证、商用地域与署名/分发义务 |
| 安全 | 漏洞扫描、内容审核、举报投诉、应急响应、访问控制、儿童数据事件升级机制 |
